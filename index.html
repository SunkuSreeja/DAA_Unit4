Algorithmic Optimization Lab | Design and Analysis of Algorithms – Unit IV

Project Overview

An interactive JavaFX application demonstrating Backtracking and Branch and Bound algorithms through practical problem-solving scenarios.

Algorithms Implemented

8 Queens

Backtracking algorithm for collision-free placement.

Hamiltonian Cycle

Backtracking for circuit routing.

Travelling Salesman Problem

Branch and Bound for optimal air cargo routes.

Knapsack

Branch and Bound for investment optimization.
